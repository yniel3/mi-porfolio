# Mi Portafolio Multilingüe con React + i18n

Hola! Este es mi portafolio personal, creado con **React** y **react-i18next** para ofrecer una experiencia multilingüe. Es un pequeño espacio donde comparto quién soy, qué hago y hacia dónde quiero ir.

## Tecnologías utilizadas

- [React](https://reactjs.org/)
- [react-i18next](https://react.i18next.com/)
- HTML + CSS + JavaScript

## Características

- Interfaz simple y amigable
- Soporte para múltiples idiomas
- Diseño adaptable (responsive)

## 📄 Licencia

Este proyecto es de uso libre. Si te inspira, ¡adelante y crea el tuyo!

## Instalación

```bash
git clone https://github.com/yniel3/mi-porfolio.git
cd mi-portafolio
npm install
npm start
```
